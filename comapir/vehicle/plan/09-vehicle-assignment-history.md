# Vehicle Assignment History

A historical log tracking all driver assignments to each vehicle over time, showing assignment periods, current assignments, and reassignment audit trail.

## Overview

The current system shows only the currently assigned driver. This feature maintains a complete history of which drivers have operated which vehicles, with assignment dates and duration, providing an audit trail and operational history.

## Business Value

- Track which driver operated which vehicle for accountability
- Historical data for incident investigation
- Driver performance tracking by vehicle
- Rotation history for fleet management
- Compliance/audit requirements

## Key Features

### 1. Assignment History List

**Columns:**
- Driver Name & Photo
- Assignment Start Date
- Assignment End Date (or "Current")
- Duration (calculated)
- Assigned By (user who made assignment)
- Reason/Assignment Notes
- Status (Active/Ended)

### 2. Current Assignment Display

- Current driver highlighted
- Assignment duration so far
- Quick link to driver profile
- Contact details

### 3. Assignment Timeline

- Visual timeline showing assignment periods
- Overlapping assignments (if any system errors)
- Gaps in assignment (unassigned periods)

### 4. Assignment Actions

- Change Driver (end current, start new)
- Remove Assignment (vehicle unassigned)
- View Driver History (link to driver's vehicle history)
- Add Notes to assignment

### 5. Driver Performance per Vehicle

- Total trips completed by driver in this vehicle
- Revenue generated by driver in this vehicle
- Accident/incident count (if recorded)
- Average rating (if applicable)

### 6. Vehicle Handover Checklist (Optional)

When reassigning vehicle:
- Document verification checklist
- Vehicle condition notes
- Fuel level recording
- Odometer reading
- Damage inspection

### New Model Required
```python
class VehicleDriverAssignment(db.Model):
    __tablename__ = "vehicle_driver_assignments"
    
    id = db.Column(db.Integer, primary_key=True)
    tenant_id = db.Column(db.Integer, db.ForeignKey("tenants.id"), index=True)
    vehicle_id = db.Column(db.Integer, db.ForeignKey("vehicles.id"), nullable=False, index=True)
    driver_id = db.Column(db.Integer, db.ForeignKey("drivers.id"), nullable=False, index=True)
    
    # Assignment Details
    assigned_at = db.Column(db.DateTime, default=datetime.utcnow)
    assigned_by = db.Column(db.Integer, db.ForeignKey("users.id"))  # User who assigned
    assignment_date = db.Column(db.Date, default=date.today)
    
    # End Assignment Details
    ended_at = db.Column(db.DateTime)
    ended_by = db.Column(db.Integer, db.ForeignKey("users.id"))
    end_date = db.Column(db.Date)
    end_reason = db.Column(db.Text)  # Driver left, rotation, vehicle sold, etc.
    
    # Notes
    assignment_notes = db.Column(db.Text)
    handover_notes = db.Column(db.Text)
    
    # Status
    is_active = db.Column(db.Boolean, default=True)
    
    # Relationships
    vehicle = db.relationship("Vehicle", backref="driver_assignments")
    driver = db.relationship("Driver", backref="vehicle_assignments")
    assigner = db.relationship("User", foreign_keys=[assigned_by])
    
    @property
    def duration_days(self):
        if self.end_date:
            return (self.end_date - self.assignment_date).days
        return (date.today() - self.assignment_date).days
```

### Update Vehicle Assignment Workflow
```python
def assign_driver_to_vehicle(vehicle_id, driver_id, assigned_by_user_id, notes=None):
    # End current assignment if exists
    current = VehicleDriverAssignment.query.filter_by(
        vehicle_id=vehicle_id,
        is_active=True
    ).first()
    
    if current:
        current.is_active = False
        current.ended_at = datetime.utcnow()
        current.end_date = date.today()
        current.end_reason = "Reassigned"
    
    # Also update the driver's vehicles relationship (backward compatibility)
    vehicle = Vehicle.query.get(vehicle_id)
    vehicle.driver_id = driver_id
    
    # Create new assignment record
    new_assignment = VehicleDriverAssignment(
        vehicle_id=vehicle_id,
        driver_id=driver_id,
        assigned_by=assigned_by_user_id,
        assignment_notes=notes,
        is_active=True
    )
    
    db.session.add(new_assignment)
    db.session.commit()
    
    return new_assignment
```

def migrate_existing_assignments():
    for vehicle in Vehicle.query.filter(Vehicle.driver_id.isnot(None)).all():
        assignment = VehicleDriverAssignment(
            vehicle_id=vehicle.id,
            driver_id=vehicle.driver_id,
